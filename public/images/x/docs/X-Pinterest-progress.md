### 📌 X 进度核对方法（2026-09-15 实测有效）

不用靠记忆，可以直接从公开数据确认发到第几天：
1. 抓 `https://x.com/<账号>` 的 HTML，正则取出推文 ID
2. 推文 ID 是 Snowflake，时间戳 = `(id >> 22) + 1288834974657`（毫秒）
3. 用 `https://publish.twitter.com/oembed?url=<推文链接>` 取回推文原文
4. 把原文在 `X-10accounts-day*.txt` 里搜一遍，命中的那天就是实际进度
