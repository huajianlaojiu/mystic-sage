**结论：没有"被封"这回事。**低表现有两个普通原因，不是玄学：

### 原因 1：Pin 指向的页面当时是坏的（主因，已修复）

已发布的 Pin 里有 **52/57 条（约 91%）指向 mysticsages.com 的博客页**，
而这些博客页在 2026-09-13 之前**全部显示 "Post not found"**（Next 16 params 写法错误）。

- 有人点进去 = 看到死页面，立刻退出
- Pinterest 会记录出站点击质量，死链落地页是负面信号
- 已修复并线上验证：20 个 Pin 落地 URL 现在**全部返回 200**

### 原因 2：新号 + 0 粉丝 + 0 收藏 = 没有排名信号

Pinterest 搜索靠"收藏/保存"这类互动度排序。新号 8 天发 137 张、
零他人互动、零收藏，Pin 排在第几百位之后，等于搜不到。

（以下"集中发 137 张 / 同模板 / 100% 自推"仍是加重因素，但不是处罚原因。）
