# Pinterest 账号恢复计划（lunaraven_tarot）

## 诊断结论

账号**未被封禁，但已被降权/静音**：Pin 不进搜索索引、不进推荐池 → 月浏览仅 155（发了 137 张）。

触发原因（反垃圾系统的典型判定）：
1. 新号 8 天内集中发 137 张
2. 全部使用同一模板（高度相似）
3. 全部指向同一域名（自推比例 100%）
4. 0 粉丝、0 对他人内容的互动

## 立刻执行（第 1-3 天）

### 1. 检查政策通知（一次性）
- Pinterest → 设置 → 查看是否有"账号审核中/违反准则"提示
- 查注册邮箱，搜 "Pinterest"，找反垃圾通知邮件
- 有通知 → 走官方申诉入口

### 2. 停止发布（7-10 天）
- 不再发任何新 Pin（含已做好的羊皮纸版、金黄版）
- 不批量删除旧 Pin（会加重异常判定）

### 3. 暂停风格对比测试
- 账号被静音时数据无效，等恢复后再测 B/C 两种风格
