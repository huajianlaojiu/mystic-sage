1. 不要所有号在同一设备登录
2. 每条推文配一张图（Canva免费做）
3. 新号每天不要超过5条
4. 内容循环使用，每2-3天可以重复
5. 品牌号不转发其他号，保持独立
6. 互动号专门用来转发和评论，制造热度
